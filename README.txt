AUTOCLICKER PRO

Запуск:
pip install -r requirements.txt
python main.py

Сборка в EXE:
Запусти build_exe.bat

Готовый файл:
dist/AutoClickerPro.exe

Управление:
F6 — старт / стоп
F7 — закрыть программу

Функции:
- Интервал кликов
- Левая / правая / средняя кнопка мыши
- Нажатия клавиатуры
- Выбор клавиши нажатием
- Одинарный / двойной клик
- Сохранение настроек
- Статистика действий
- Красивый чёрно-белый интерфейс
